# Ecommerce Platform

A full-stack e-commerce application built as a hands-on learning project.

## Technology Stack

- Frontend: React + TypeScript
- Backend: Java 21 + Spring Boot
- Database: PostgreSQL 17
- API: REST
- Build: Maven and npm
- Version Control: Git
- Containerization: Docker

## Development Roadmap

1. Project setup and architecture
2. Product and category APIs
3. React storefront
4. Authentication, cart, and orders
5. Payment sandbox and testing
6. Docker and deployment
